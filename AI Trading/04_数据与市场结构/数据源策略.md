# 数据源策略

结论：数据源按资产类别分层，不能把所有标的都简化为“OKX 主源 + 其他交易所校验”。

## 数据源角色

| 角色 | 用途 |
| --- | --- |
| 执行/撮合价格源 | 回测、模拟盘、未来实盘对齐 |
| 主参考价格源 | 趋势、结构和跨市场事实背景 |
| 异常校验源 | 插针、缺口、局部异常识别 |
| 宏观/时段背景源 | 过滤器、解释和复盘 |
