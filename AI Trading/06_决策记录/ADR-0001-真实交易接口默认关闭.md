# ADR-0001-真实交易接口默认关闭

## 结论

真实交易接口默认关闭，P6 不引入真实下单能力。

## 背景

当前项目处于研究、回测、看板和模拟盘准备阶段。任何真实资金行为都需要独立权限隔离、人工审批、额度限制、审计日志和熔断机制。

## 决策

- P6 只做公开行情、虚拟订单、虚拟持仓和虚拟权益曲线。
- 不收集、不保存 API secret。
- 不在看板中加入真实交易按钮。

## 后果

- 降低误操作风险。
- P7 需要单独设计实盘权限隔离。
