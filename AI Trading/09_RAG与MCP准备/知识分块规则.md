# 知识分块规则

结论：未来 RAG 分块要优先降低噪声，而不是最大化收录量。

## 文件粒度

- 一个核心概念一个文件。
- 策略族单独成卡。
- 决策单独成 ADR。
- 复盘单独成记录。
- 原始研究不要直接拆进长期记忆。

## 元数据

每个长期文件至少包含：

- `type`
- `status`
- `updated`
- `tags`

策略文件额外包含：

- `strategy_family`
- `implemented` 或 `research_only`

## 内容格式

- 先写结论。
- 表格表达状态。
- 代码路径用反引号。
- 不写未验证推断。
- 不混合当前实现和未来设想。
