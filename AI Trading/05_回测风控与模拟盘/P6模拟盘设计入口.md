# P6模拟盘设计入口

结论：P6 应复用 P4 的信号、风控和执行模型，新增模拟盘事件循环与结构化日志，而不是重写交易路径。

## 目标链路

```text
PublicMarketData -> StrategySignal -> RiskDecision -> VirtualOrder -> PositionState -> EquityCurve -> ReviewLog
```

## 设计原则

- 只读公开行情。
- 只生成虚拟订单。
- 虚拟订单必须来自标准信号和 RiskEngine。
- 结构化日志是 Agent 慢路径唯一输入。
- 不引入真实交易权限。

## 核心对象建议

| 对象 | 职责 |
| --- | --- |
| MarketEvent | 行情事件 |
| SignalEvent | 策略信号事件 |
| RiskEvent | 风控通过或拒绝 |
| VirtualOrderEvent | 虚拟订单 |
| PositionEvent | 虚拟持仓变化 |
| EquityEvent | 虚拟权益变化 |
| ReviewEvent | 复盘和解释输入 |
