# 风控系统

结论：风控层是策略信号和模拟/真实执行之间的唯一闸门；研究收益不得通过放宽 RiskEngine、成本、margin、notional cap、stop、target 或正式出场边界制造。

## 当前默认

- 单笔风险：`0.5% equity`。
- 单日最大模拟回撤：`2%`。
- 总体硬熔断：`5%`。
- 达到 `1R` 后部分止盈。
- 成本计入手续费、点差、滑点和资金费率。
- 真实交易接口默认关闭。
- LR Restricted Variant B 的正式研究限制包含 `portfolio_heat_cap=0.05`。
- `live_trading_enabled=false`。

## 入口

- `trading_system/backtest/risk.py`
- `trading_system/backtest/execution.py`
- `trading_system/backtest/contract_risk.py`
- `research_pipeline/core/audit/`

## 不允许

- 策略直接生成订单。
- Agent 覆盖风控。
- proposal 自动生效。
- proposal / diagnostic / summary rows 进入 performance metrics。
- 通过降低 fee、funding、slippage、margin、notional cap、stop、target 或出场约束制造收益。
- 把 B profile、unrestricted Variant B、Full original family 或未执行 proposal rows 写入正式主配置。

## LR 当前正式研究边界

| 项目 | 结论 |
| --- | --- |
| 正式候选 | Restricted Variant B |
| 风险限制 | `portfolio_heat_cap=0.05` |
| 正式 profile | C profile |
| B profile | diagnostic-only |
| live trading | disabled |
| execution lineage | closed trade 必须有 `trade_id` / `execution_id` / `candidate_id` / `event_id` |
