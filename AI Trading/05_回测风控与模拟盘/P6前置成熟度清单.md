# P6前置成熟度清单

## 结论

P6 模拟盘暂缓。进入 P6 前，必须先完成数据、回测、风控、诊断、proposal、ReviewLog、配置回滚和 Research Pipeline 审计闭环。

## 必须 hardened 的模块

| 模块 | P6 前要求 |
|---|---|
| 数据质量与覆盖 | 覆盖范围明确，缺口可诊断，异常不会静默进入回测 |
| confirmed K 线 | 不使用未确认 K 线，多周期对齐可审计 |
| 撮合与回测 | 无前瞻，成本、滑点、funding、margin、stop/target 口径明确 |
| RiskEngine | 不允许绕过，所有模拟执行必须经过风险检查 |
| 信号与拒绝诊断 | 可解释每个信号通过/拒绝原因 |
| performance metrics | 只使用 closed_trade rows |
| closed_trade lineage | 可追溯 execution、candidate、event、timeseries |
| proposal 审批 | proposal 不自动改正式配置 |
| ReviewLog / LLM 复盘输入 | Agent 只进慢路径，不进入买卖决策热路径 |
| P5 看板 | 作为诊断入口，不作为交易控制面 |
| 配置版本与回滚 | formal config、proposal、baseline 和 rollback 指令可追溯 |

## 暂缓事项

- 黄金/纳指数据源。
- 正式 P6 模拟盘。
- 新策略 formalization。
- P5 大改。
- storage 大清理前置执行。
