# 待补齐清单

结论：本页是后续计划的唯一长期待执行清单；根目录规划文档只做入口，不再维护另一份正文。

## 使用规则

- `P6 模拟盘前必须补齐` 是进入正式 P6 模拟盘的 gate。
- `P1-P5 进阶增强` 是后续完善 backlog，默认不阻塞 BTC/ETH paper v1，除非单项被提升为 gate。
- 若某阶段先实现 MVP，MVP 外的完整功能、增强项和暂缓能力必须同步写入本页，不能只靠上下文记忆保留。
- 已完成事项必须从本页移出，并记录到 [[里程碑日志]] 或 [[当前完成度]]。
- 新任务优先写入本页，再由阶段页引用，避免散落在多个页面。

## P6 模拟盘前必须补齐

- 实时公开行情事件源接入 paper 模拟执行链路。
- ReviewLog 日志持久化和看板读取。
- 虚拟权益曲线。
- 退出事件与持仓生命周期。
- position-aware 回测扫描，避免同一资产同一策略在持仓期重复开仓。
- 多周期 confirmed K 线无前瞻审计。
- 手续费、滑点、资金费率、成本后 R 倍数。
- 策略失败案例归因页。
- BTC/ETH 历史数据覆盖补齐到正式回测要求。

## P1-P5 进阶增强

### P1 数据进阶

### P2 指标与特征进阶

- OB/FVG 生命周期。
- ToD RVOL。
- AVWAP / Session VWAP。
- session high/low、previous day high/low。
- VSA 细分特征库：高量低结果、停止量、吸收、缩量测试、放量突破。
- SMC 结构特征：Swing、BOS、CHoCH、Equal High/Low、流动性池。
- CVD/OI、订单簿、taker imbalance 先作为研究或 wrapper 特征，不进入当前 v1 入场必要条件。

### P3 策略族进阶

- 优先实现 [[07_compression_expansion_breakout]]，因其与趋势延续和压缩突破路径最接近。
- 后续实现 [[02_stopping_volume_retest]]、[[03_absorption_box_break]]、[[05_failed_breakout_effort_result]]、[[06_climax_exhaustion_reversal]]、[[08_hvn_fvg_rejection_trap]]。
- 每个新增策略族必须输出标准 `StrategySignal`，不得直接下单或绕过 `RiskEngine`。
- 每个新增策略族必须同步补信号漏斗、拒绝原因和 Near Miss 诊断。

### P4 回测与绩效进阶

- P4 跑完后保存 artifact，P5 直接读取 artifact 摘要和明细。
- 更完整绩效报告。
- QuantStats / empyrical 仅通过报告层 adapter 接入，不替代 `BacktestSummary` 或 ranking 主口径。
- vectorbt 仅保留为离线研究和参数扫描候选，不替代 P4/P6 主链路。
- LLM proposal 队列。
- 外部指标 wrapper 扩展。

### P5 看板与诊断进阶

- P5 读取 P4 artifact，避免每次打开看板重复运行完整回测。
- P5 读取 P6 ReviewLog 持久化结果后，展示权益曲线、交易列表、风控拒绝原因和复盘摘要。
- 策略失败案例归因页接入看板。
- 数据质量、信号漏斗、风控拒绝和 Near Miss 支持按资产、周期、策略族 drill-down。

## 重点风险项

- 非加密资产数据源不能沿用 Crypto 简化模式。
- Agent proposal 不得自动变成正式参数。
- 模拟盘不能混入真实交易权限。
- 诊断项不能被误写成入场条件。
