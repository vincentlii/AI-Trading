# 风险边界

结论：项目当前是量化研究、回测、模拟盘与复盘系统，不是自动实盘交易系统。

## 禁止事项

- 不保存 API key、secret key、passphrase。
- 不接入未经人工审批的真实资金自动下单。
- 不允许 Agent 直接生成真实订单。
- 不允许 Agent 绕过风控、自动改正式配置或自动应用 proposal。
- 不把 XAUT/USDT 当作全球黄金唯一事实源。
- 不把低质量指数币、指数代币或未授权 CFD 当作 Nasdaq 主参考源。
- 不混合不同交易所 K 线生成综合成交价格。

## 风控原则

- 策略只输出标准信号和解释载荷。
- 风控层统一处理仓位、止损、止盈、冷却和熔断。
- 回测与模拟盘只消费标准信号、风控决策和模拟订单。
- 真实交易权限必须独立阶段处理，不能混入 P6。

## Agent 边界

Agent 可以做：

- 解释信号。
- 解释风控拒绝原因。
- 做亏损归因。
- 做红队审查。
- 生成参数 proposal。

Agent 不可以做：

- 自动下单。
- 自动改正式参数。
- 绕过 RiskEngine。
- 把复盘结论直接写入执行热路径。
