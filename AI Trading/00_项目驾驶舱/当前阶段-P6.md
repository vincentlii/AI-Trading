## P6 目标

建立公开行情到虚拟订单、虚拟持仓、虚拟权益曲线的模拟盘事件循环，并输出可供复盘 Agent 读取的结构化日志。

## P6 边界

| 包含 | 不包含 |
| --- | --- |
| 公开行情读取 | 真实账户交易 |
| 虚拟订单 | API secret 管理 |
| 虚拟持仓 | 自动实盘下单 |
| 虚拟权益曲线 | Agent 直接改参数 |
| 信号解释 | 绕过 RiskEngine |
| 风控拒绝解释 | 未审批 proposal 生效 |
| 复盘报告 | 实盘权限入口 |
