# 1. 对研究报告的总体判断

## 可采纳的核心结论

这份报告最有价值的地方有 5 点：

1. **成交量基线不应继续用简单 rolling RVOL**  
    报告建议使用 ToD/DoW 季节性 RVOL，并对 volume 做 log transform + EWMA baseline，这是正确方向。报告明确指出 BTC/ETH 虽然 24/7 交易，但存在明显日内和星期结构，因此简单滚动成交量会把亚洲、欧洲、美国时段混在一起，导致 volume filter 失真。
    
2. **趋势延续和扫荡反转必须分开建模**  
    报告把趋势延续定义为 aggressive orders 持续推动，把流动性扫荡定义为被动吸收与流动性耗尽，这与你当前两个 setup 的问题高度匹配。
    
3. **当前最大问题确实不是“放宽风控”，而是 stop/invalidation 设计**  
    报告明确指出固定 ATR 止损在高波动 crypto 中会导致仓位萎缩和 R 倍数失真，并建议引入结构止损与 MAE/MFE 诊断。
    
4. **出场应该异构化**  
    趋势延续类更适合 trailing / chandelier / 让利润奔跑；流动性扫荡类更适合结构目标、分批兑现和时间截断。这个方向与你之前的策略研究是一致的。
    
5. **回测必须强制处理 same-bar ambiguity**  
    报告建议当同一根 K 同时触及止损和止盈时，优先按止损处理；若有低周期数据则向下穿透重放，否则执行悲观成交。这一点应直接纳入回测审计。

# 5. Stop / Invalidation Proposal

这是最关键部分。我的建议是：**不要直接放宽 `max_stop_atr_multiple`，而是重写 stop 生成逻辑。**

## 当前问题

报告指出固定 ATR 止损在高波动 crypto 中会导致仓位萎缩、目标 R 失真和期望值恶化。  
你当前回测也显示所有主要 risk reject 都集中在 `stop_distance_too_far`。

## 建议方案

|Proposal ID|类型|当前|建议|
|---|---|---|---|
|RISK-STOP-001|反转类止损|sweep extreme ± ATR|改为 sweep extreme ± small buffer|
|RISK-STOP-002|continuation 止损|统一 ATR 外扩|改为 pullback swing / breakout acceptance level + buffer|
|RISK-STOP-003|stop cap|`max_stop_atr_multiple=3.0`|保留 3.0 作为 hard gate|
|RISK-STOP-004|沙盒测试|无|允许 5.0 仅用于 C profile 敏感性分析|
|RISK-STOP-005|MAE 止损|暂无|等 closed trades 足够后再启用 80%/85% MAE|

## 初始 stop 规则建议

### 流动性扫荡做多

```text
stop_candidate_1 = sweep_low - max(0.10 * ATR_entry, 3 * spread)
stop_candidate_2 = reclaim_bar_low - max(0.10 * ATR_entry, 3 * spread)
final_stop = min(stop_candidate_1, stop_candidate_2)

reject if stop_distance > 3.0 * ATR_entry
reject if target_R < 1.5
```

### 流动性扫荡做空

```text
stop_candidate_1 = sweep_high + max(0.10 * ATR_entry, 3 * spread)
stop_candidate_2 = reclaim_bar_high + max(0.10 * ATR_entry, 3 * spread)
final_stop = max(stop_candidate_1, stop_candidate_2)

reject if stop_distance > 3.0 * ATR_entry
reject if target_R < 1.5
```

### 趋势延续做多

```text
stop = pullback_swing_low - max(0.15 * ATR_entry, 3 * spread)
reject if stop_distance > 3.0 * ATR_entry
```

**验收目标：**

|指标|目标|
|---|--:|
|stop/ATR P50|≤ 1.5|
|stop/ATR P75|≤ 2.2|
|stop/ATR P90|≤ 3.0|
|stop/ATR > 3.0|hard reject|
|approved trades|显著高于当前|
|closed trades|足够支持 MAE/MFE 分析|
