# LR 研究暂停与证据保存 2026-06-21

## 结论

LR causal rebuild 正式停止。当前没有 formal research candidate，不进入 holdout、P6 或 live path；Restricted Variant B 仅保留为 historical invalidated evidence。

停止原因不是单一参数或成本问题，而是正确因果语义下的上游 edge 太薄且不稳定：15m event 路径噪声高，1H same-bar + 15m confirmation 的表面改善主要来自 confirmation chase 与 R geometry，固定时间漂移在 physical-event 去重和分组后不能稳定延续，真实 execution 无法覆盖既定成本。

| Restricted Variant B historical repair | 5,078 trades，total_net_R=-356.64，PF=0.722 | 旧 183 笔高收益不能迁移到正确 bar-close 和 execution 语义 |

| v3 geometry | reclaim-reference +1R-first 68.92%；confirmation-reference 47.64% | confirmation 后重新承担完整风险时优势消失 |
| Fixed horizon unique events | 12h +0.0941%，24h +0.0694%，36h -0.0257%，48h +0.0132% | 只有弱短线冲击，不支持稳定长持 |

上述 diagnostic R、path-order 和 fixed-horizon return 不是交易绩效。真实收益只读取 audited `row_type=closed_trade`。

## 机制结论

- 15m 的问题同时包括周期偏低、event definition 过宽和双向路径噪声；不能同时承担 liquidity event 与 execution 定义。
- 1H same-bar reclaim 更符合 failure auction 语义，但 reclaim 本身不足以形成可交易 edge。
- PDH/PDL 最接近共识流动性；confirmed swing 次之；Session H/L 缺 first-touch、active-session 与 confluence 时只是宽基线。
- VPA 有弱到中等 attribution 价值；normal/elevated effort 常优于 extreme，但不支持权重、score 或正式 gate。
- Structural confirmation 必须同时通过 event-reference 和 confirmation-reference 检查；只改善前者属于几何美化。

## 工程修正

本轮保留并推广到全部策略的修正：

- no-lookahead 检查要求 `bar_confirmed`、`no_lookahead_safe` 显式为 `true`。
- same-bar ambiguity 必须使用 forced pessimistic exit。
- Full Audit 同时识别 `run_manifest.json` 与 `research_manifest.json`。
- layered pipeline 默认使用 preset enabled setups，防止 setup 串扰。
- execution candle 按标的与周期缓存，避免重复数据库扫描。
- RiskEngine 支持默认关闭的 notional cap 缩仓；缩仓不绕过 leverage、heat 或最低实际风险检查。
- LR 不再跳过 market/VPA context；实验性的 LR protection、momentum deadline 未进入共享 execution engine。

## 重启条件

只有同时满足以下条件才允许重新研究 LR：

1. 提出不同于当前 sweep/reclaim + confirmation 的上游机制，并预注册可证伪标准。
2. 先在 development 上证明 unique physical events 的跨年、BTC/ETH、long/short 稳定性。
3. event-reference 与 confirmation-reference 均改善，且 confirmation chase 可控。
4. 固定时间漂移和真实 execution gross edge 足以覆盖既定成本。
5. 不放宽 RiskEngine、成本、stop、notional cap，不读取封存 holdout。

在此之前，项目转向其他策略研究。
