# 第三方库接入边界

结论：第三方库只作为 adapter、wrapper、报告工具或研究工具使用，不进入交易核心领域模型。

## 可接入范围

| 类别 | 可接入层 | 当前状态 | 禁止事项 |
| --- | --- | --- | --- |
| QuantStats | 报告层 / P5 展示层 | optional adapter | 不替代项目 ranking 或 `BacktestSummary` |
| empyrical | 报告层 / 校验层 | optional adapter | 不作为唯一绩效口径 |
| TA-Lib / pandas-ta | 指标 wrapper 层 | optional wrapper | 不直接生成策略信号 |
| vectorbt | 离线研究层 | research-only | 不替代 P4/P6 主回测和模拟盘 |
| OpenBB | 研究数据探索层 | research-only | 不作为严肃回测主价格源 |
| CME / Databento / IBKR | 未来数据 adapter 层 | candidate | 不与 OKX/Binance 混成综合成交价 |

## 核心对象保护

以下对象不得持有或返回第三方库专属对象：

- `StrategySignal`
- `RiskEngine`
- 无前瞻撮合执行路径
- `SimulatedOrder`
- `PositionState`
- `TradeLog`
- `ReviewLog`
- LLM proposal 审批机制

## 接入记录模板

每次引入第三方库，都必须记录：

- 引入目的。
- 接入层级。
- 输入输出对象。
- 禁止进入的核心对象。
- 版本和维护风险。
- 测试命令与结果。
- 指标或绩效口径差异。
- 失败回退方式。

## 当前实现

- `trading_system.reports.performance` 提供绩效报告 adapter，优先输出项目主口径指标；QuantStats / empyrical 缺失时仍可运行。
- `trading_system.indicators.external_wrappers` 提供基础指标校验 wrapper；外部指标库缺失时只返回受控状态，不影响策略信号。
- P5 看板只新增绩效报告 tab，不重写现有 v1 看板结构。
