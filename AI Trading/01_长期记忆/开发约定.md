# 开发约定

结论：本页是长期开发约定的权威页；根目录 `开发记录.md` 只保留薄入口。

## 关键约定

- 当前默认在 `master` 分支开发，除非用户明确要求不使用 worktree。
- 项目独有依赖、数据、缓存和测试数据库优先放在 `D:\交易系统` 内。
- `AI Trading/` Obsidian vault 是唯一长期知识源。
- 根目录长期文档只保留入口、命令和恢复路径，不维护另一份正文。
- 正式配置进入 Git；Agent 只能生成 proposal。
- 第三方库只能通过 adapter、wrapper、报告层或研究工具层接入；完整规则见 [[第三方库接入边界]]。
- `.venv` 外的 `__pycache__` / `.pyc` 在任务完成前清理。
- 新生产代码必须有测试。
- 文档类小任务至少运行 `git diff --check`。
- 每完成一个明确小阶段，完成验证后提交一次 Git commit；提交范围只包含该小阶段相关文件，不混入遗留变更。
