## Research Pipeline 验证

LR finalization 后，策略研究进入 formal candidate 前必须至少通过 full-audit、strategy regression、artifact validation 和相关测试。

```powershell
.\.venv\Scripts\python -B -m unittest tests.test_liquidity_reversal_final_config -v
.\.venv\Scripts\python -B -m unittest discover -s research_pipeline\tests -v
.\.venv\Scripts\python -B -m compileall research_pipeline trading_system scripts
python -m research_pipeline.cli.research full-audit --strategy liquidity_reversal --artifact-dir storage\backtest_cache\pr11g_clean_rebuild\lr_combined_fix --output-dir storage\research_runs\liquidity_reversal\final\post_commit_full_audit
python -m research_pipeline.cli.research strategy-regression-check --strategy liquidity_reversal --baseline-dir tests\fixtures\regression_baselines\liquidity_reversal\stage6e_10000w --summary-dir tests\fixtures\regression_baselines\liquidity_reversal\stage6e_10000w --output-dir storage\research_runs\liquidity_reversal\final\post_commit_strategy_regression
python -m research_pipeline.cli.research validate-artifacts --artifact-index docs\research\liquidity_reversal\final_evidence\artifact_index.json
```

Full Audit Gate 通过标准：

- performance metrics 只能来自 `row_type=closed_trade`。
- `proposal_candidate`、`sizing_diagnostic`、`diagnostic_only`、`summary_row` 不进入收益统计。
- closed trade 必须有 `trade_id`、`execution_id`、`candidate_id`、`event_id` 和可验证时间链路。
- no-lookahead、metric recompute、proposal boundary、artifact integrity 和 regression baseline 无 blocking issue。

## 回测运行记录

`run_btc_eth_p4_4_backtest.py` 和 `run_btc_eth_swap_proposal.py` 默认把每次运行记录到 `storage/backtest_runs/`。

记录内容包括运行索引、summary、回测 rows CSV 和 preset snapshot。只有明确使用 `--no-record` 时才关闭记录。

SWAP proposal 支持分层缓存模式，缓存默认写入 `storage/backtest_cache/`：

```powershell
.\.venv\Scripts\python scripts\run_btc_eth_swap_proposal.py --mode candidate_only --db storage\history.duckdb --max-entry-windows 200
.\.venv\Scripts\python scripts\run_btc_eth_swap_proposal.py --mode filter_replay --db storage\history.duckdb --max-entry-windows 200
.\.venv\Scripts\python scripts\run_btc_eth_swap_proposal.py --mode gate_ablation --db storage\history.duckdb --max-entry-windows 200
.\.venv\Scripts\python scripts\run_btc_eth_swap_proposal.py --mode full_backtest --db storage\history.duckdb --max-entry-windows 200 --cost-tier base --cost-tier stress --cost-tier harsh
```
